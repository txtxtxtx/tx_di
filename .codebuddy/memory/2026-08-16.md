# 2026-08-16

## admin_api 配置路径改为绝对路径

- `examples/tx_admin/admin_api/src/main.rs::resolve_config_path`：返回值统一为**绝对路径**。
- 逻辑：`CONFIG_PATH` 环境变量 > 当前目录 `configs/config.toml` > 仓库约定 `examples/tx_admin/config/config.toml`；相对路径用 `std::env::current_dir().join()` 锚定（获取 CWD 失败时退化为原始相对路径），最后 `Box::leak` 返回 `&'static str`（与 `app_loop!` 宏的 `config = <expr>: &str` 兼容）。
- 注意：fallback 第一个路径是 `configs/config.toml`（复数，用户改过，不是 `config/config.toml`）。
- 编译验证：`cargo check -p admin_api --bin admin_api` 通过。

## 启动失败修复（配置未加载 → 默认端口 8080 被占 → os error 10013）

- 现象：`cargo run -p admin_api`（CWD=examples/tx_admin）启动后 Web 监听 `127.0.0.1:8080`（默认值），`WebPlugin async_run` 绑定失败 os error 10013（8080 被占用/保留），且 CORS=false、max_body=10MB、toasty ERROR "读取配置文件失败 path="。
- 根因：上一轮 `resolve_config_path` 把 fallback 约定路径 `examples/tx_admin/config/config.toml` 盲目按 CWD 锚定，从 `examples/tx_admin` 运行时拼出 `examples/tx_admin/examples/tx_admin/config/config.toml`（不存在）→ `load_local_toml` 返回空 Table → 所有组件走默认值。
- 修复：`resolve_config_path` 改为按**存在性探测**候选：`<CWD>/config/config.toml` > `<CWD>/configs/config.toml` > `<CWD>/examples/tx_admin/config/config.toml`；`CONFIG_PATH` 环境变量优先不探测；兜底绝对化约定路径。新增辅助 `absolutize()`。
- 连带修复：`tx_di_toasty/src/plugin.rs::change_auto_schema_closed` 对空 `config_path`（内存配置启动）跳过、读取失败降为 debug（原为 ERROR 噪音）。
- 验证：`cargo check -p admin_api -p tx_di_toasty` 通过。用户重跑应监听 `::` :8888。
