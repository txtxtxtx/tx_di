## 经验

- Windows 下并发 cargo 构建易触发页面文件不足（os error 1455）→ 残留 0 字节 rmeta / 损坏 PDB，导致 E0786/LNK1207。修复：`cargo clean -p <pkg>` + `CARGO_BUILD_JOBS=2`。
- PowerShell 的 `Remove-Item` 不能直接吃管道输入（报 InputObjectNotBound）；用 `cargo clean -p` 更可靠。
